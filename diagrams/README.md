# Diagrams

Six architecture diagrams, hand-written as SVG. Vector, so they scale to any
size without blurring, and the text is real text — selectable, searchable, and
editable in any editor.

```
diagrams/
  *.svg          light theme, white background — source of truth
  dark/*.svg     dark theme, generated by make-dark.py — do not edit by hand
  png/*.png      3200 × 1800 (2× of 1600 × 900), rendered from dark/
  make-dark.py   light -> dark colour mapping
```

| # | Diagram | Shows |
| --- | --- | --- |
| 1 | `1-data-estate` | Sources → ingest → model → serve |
| 2 | `2-icl-study-design` | ICL: design fixed before collection, instruments, field QA, outputs |
| 3 | `3-phc-data-explorer` | PHC Data Explorer pipeline with the supervised AI branch |
| 4 | `4-glide-quality-gate` | GLIDE: 16-rule engine and the human validation gate |
| 5 | `5-geospatial-rules` | Geopoint parsing, accuracy threshold, grid-snap duplicate detection |
| 6 | `6-ga4-three-era-reconciliation` | Three measurement eras into one article-level table |

All 16:9, so they drop straight into slides.

## Editing

**Edit the light SVGs only.** Then regenerate everything downstream:

```bash
python make-dark.py          # light *.svg  ->  dark/*.svg
```

Then re-render the PNGs (Edge or Chrome, headless — no extra install):

```powershell
$edge = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
foreach ($s in Get-ChildItem dark\*.svg) {
  & $edge --headless=new --disable-gpu --hide-scrollbars `
          --force-device-scale-factor=2 --window-size=1600,900 `
          --screenshot="png\$($s.BaseName).png" ("file:///" + ($s.FullName -replace '\\','/'))
}
```

`--force-device-scale-factor=2` is what turns a 1600 × 900 viewport into a
3200 × 1800 file. Raise it to 3 for print.

## Palette

| Role | Light | Dark |
| --- | --- | --- |
| Canvas | `#FFFFFF` | `#0D1117` |
| Raised surface | `#FFFFFF` | `#161B22` |
| Text and connectors | `#334155` | `#C9D1D9` |
| Process nodes | `#2E8B74` | `#3DA88C` |
| Decision diamonds | `#D98A2B` | `#E09B3D` |
| Data stores | `#F1F5F9` / `#CBD5E1` | `#161B22` / `#30363D` |
| Flagged, rejected — nothing else | `#B4483C` | `#D9705F` |
| Pending, not rejected | `#64748B` | `#8B949E` text, `#57606A` fill |

Two cases in `make-dark.py` are deliberately not a straight substitution, and
both would be silent bugs if they were:

- **White means three things.** Canvas and label masks, card surfaces, and text
  sitting on teal. A blanket replace turns every white label invisible, so the
  class-scoped cases are rewritten first and `.white-label` is never touched.
- **Pending needs two greys.** `#64748B` lightens to `#8B949E` for labels and
  lines, but as a *filled block* carrying white text that is about 2.6:1 —
  under the 4.5:1 floor. The block is pinned to `#57606A` instead.

Type is Inter with a Helvetica and Arial fallback. When an SVG loads as an
image the browser will not fetch a webfont, so **the fallback is what actually
renders**. For true Inter, open the SVG in a tool where the font is installed.

## Why the profile README still uses Mermaid

Mermaid re-themes itself to whichever mode the reader is in, and it diffs
cleanly in review. These files are for everywhere Mermaid does not reach —
slide decks, a CV, LinkedIn, PDF, print.
